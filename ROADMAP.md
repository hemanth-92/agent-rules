# Roadmap

## Phase 1 — Portable kit foundation

**Outcome:** Installable Codex config, core skills, and validation.

**Exit criteria:**

- install + validate scripts pass
- core skills present and documented
- repository published on GitHub

## Phase 2 — Multi-agent and project bootstrap

**Outcome:** Claude/Grok install targets and per-project template bootstrap.

**Exit criteria:**

- `--claude` and `--grok` install paths work
- `bootstrap-project.sh` is safe and idempotent without `--force`

## Phase 3 — Ongoing skill growth

**Outcome:** Add skills only when a real repeated workflow justifies them.

**Exit criteria:**

- each new skill has front matter, docs entry, and validation coverage
